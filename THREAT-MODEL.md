# Threat model

Per-feature view of what Symbiote detects or prevents, how an attacker would try to evade it, and what remains.
Mappings use the OWASP Top 10 for Agentic Applications (ASI) and MITRE ATLAS technique ids.

| Feature | Detects / prevents | Evasion | Residual risk and compensating control |
|---|---|---|---|
| Tool-definition pinning (`tooldef/v1`, `toolset/v1`) + Gateway Allowlist Bundle | Rug pulls and tool poisoning after approval (ASI04; AML.T0109, AML.T0110): any change to model-visible name, description, schema or annotations is a digest mismatch | Time-gated poisoning (benign for the first calls, hostile later); moving semantics behind a remote `$ref`; a gateway that digests SDK-normalised JSON instead of raw JSON | Re-verify per session, per `tools/list`, on `list_changed` and per call; remote `$ref` flagged (`SYM-TOOL-005`); conformance vectors and a reference verifier published. An interface-identical backend compromise is invisible to any schema hash — effects must be enforced at the gateway, sandbox or network boundary |
| Server identity binding (endpoint origin, package digest, instructions digest, signer) | Server substitution, instructions-field injection, dependency confusion on stdio launchers | Takeover of the same DNS origin or registry entry | Floating launchers flagged (`SYM-MCP-002`); TLS and signer identity constraints; origin takeover is outside the BOM |
| Declared vs approved vs deployed vs observed diff | Shadow tools, undeclared sub-agents, model re-routing, new memory writers (ASI10, ASI04) | Acting between observation windows; suppressing telemetry; serving one `tools/list` to the collector and another to the agent | Observed snapshots carry window and staleness; enforcement in the agent's own gateway path removes the split view; coverage states when the runtime surface was not observed |
| Rule of Two / lethal-trifecta flag | Architecture-level exfiltration paths (AML.T0086) before deployment | Mislabelling an input source as trusted; declaring a destructive tool read-only | Trust tiers and annotations are assurance-tagged; observed side effects override declared ones; absent annotations default to worst case; unknown inputs yield `indeterminate`, never a pass |
| Least-privilege gap | Over-scoped tokens and roles (ASI03) | Undocumented required scopes; grants split across identities | `required` is itself a claim with assurance; identity fan-out is answerable from the incident index |
| Floating / unpinned dependency flags | Silent model swaps behind aliases; `npx -y pkg@latest` servers (AML.T0010) | Provider-side swap with an unchanged snapshot id | Behavioural fingerprint claim with expiry (weak detection); provider evidence when it exists |
| Unsafe serialization and `trust_remote_code` | Code execution on load (ASI05) | Polyglot files; vulnerable loaders; Jinja chat-template injection | Scanner evidence by digest; chat template flagged executable; loader CVEs out of scope |
| Signature verification with identity constraints | Forged or self-signed "verified" claims; name-only bindings | Compromise of the trusted signer's OIDC identity; forcing fail-open through log unavailability | Identity constraints are operator-owned; fail closed on verification errors in gateway mode; `signature-valid-unconstrained` can never be read as verified |
| Registry name-resolution record | Typosquatting, slopsquatting, deleted or deprecated entries, re-registered namespaces (AML.T0010) | Legitimately owned look-alike namespaces; publisher account compromise | Publisher-identity revocation propagates; typosquat distance is heuristic; the MCP registry has no attestation fields, so signer facts come from package ecosystems |
| Revocation (`trust-status/v1`) and anti-rollback | Replaying an old approved snapshot or allowlist; stale revocation lists | Blocking distribution of the new list; rolling back the verifier's state file | Lists expire and fail closed; state-file integrity is the operator's responsibility (signed or immutable storage recommended) |
| Salted Merkle redaction | Attack-map leakage from full BOMs while keeping verifiability | Inferring redacted content from leaf counts and kinds; correlating leaf hashes across documents | Per-leaf salts derived from a withheld nonce prevent dictionary attacks on redacted leaves; leaf kinds remain visible by design |
| Coverage and unknown-vs-absent | Claims of absence made without having looked | None needed — the design refuses to assert absence without coverage | Human readers may still over-trust; the Verified level requires every surface queried |
| OpenTelemetry observed layer | Undeclared invocations, routing, spawns (ASI10) | Disabling or forging instrumentation | Spans are `observed` evidence, never `verified`; a forged trace can add noise but cannot upgrade assurance |
| Evaluation binding to configuration digests | Stale "passed red team" claims applied after model, prompt or tool changes | Evaluating a benign configuration then swapping | Subjects are digests; `SYM-EVAL-001` invalidates on any change; third-party assessor flag |
| Determinism and content-addressed serial numbers | Tampered re-exports; duplicate serials | Changing timestamps to force new identifiers | Deterministic mode pins timestamps to the snapshot time; `serialNumber` is a UUIDv5 of the Merkle root; model-digest triangulation across formats |
