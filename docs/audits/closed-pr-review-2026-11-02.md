## Remaining product and qualification decisions

The experimental foundation includes a salted Merkle selective-disclosure/companion protocol and full snapshot chain format, OPA/Rego export/parity, Kubernetes/telemetry import contracts, broader provider/client tables and signed incident/migration APIs. These are not automatically supported by the current `nexus_symbiote` package. Current source provides separately versioned runtime contracts, conservative imports, supported static collectors and lineage records. Any broader port needs an explicit compatibility/threat-model decision; primary discovery remains Nexus-ShadowScan.

The configured hosted matrix targets Ubuntu/Python 3.11–3.13. This audit's local validation uses Python 3.12; it does not qualify macOS/Windows or establish fleet isolation and identity enforcement. The 18 security contracts and eight inventory cases are finite regression corpora, not field-accuracy estimates or percentile rankings. A genuine hosted candidate run is still required for project-owned build/benchmark attestations. Publication preflight observes live controls during the build; administrators must review current controls and the exact artifact run at environment approval.
