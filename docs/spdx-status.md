# SPDX export status

SPDX output is temporarily unavailable. The previous projection was not established
to conform to SPDX 3.0.1 and omitted required creation and AI-profile information.
It must not be consumed as an SPDX document. Native JSON and CycloneDX output remain
available, subject to their own documented limitations.

Restoring SPDX output requires an implementation tested with the official schema and
profile constraints, round-trip tests, and an explicit loss report for semantics that
cannot be projected. The legacy private implementation is retained as migration
material, not as a supported output path.
