# Recorded rounds

One directory per round, named by its date. Each holds `REPORT.md`, rendered from `scorecard.json`, which carries every per-case outcome behind the scores, and `NOTES.md`, which explains the outcomes a number does not. Read the [method](../METHOD.md), and its limits, before quoting a number.

A round is comparable with another only when both name the same benchmark version and corpus digest.
